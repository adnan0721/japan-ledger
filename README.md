# 旅費帳本

手機用的日本旅遊記帳 PWA。一次旅行一個專案，離線可用，只有同步、辨識收據和整理總表需要網路。

網址：`https://adnan0721.github.io/japan-ledger/`

## 功能

- **記帳**：金額（日圓）、類別、付款方式、日期、時間、地點（有輸入建議）、多行備註、收據照片。自動換算約合台幣。
- **統計**：總額、約合台幣、今日支出、日均，可依類別篩選，明細依日期與時間排序。
- **專案**：每次旅行一個專案，有出發日、回程日、多行備註、匯率與持有現金。總額卡片顯示現金剩餘（只有「現金」付款會從持有現金扣除）。
- **只保留目前專案**：手機只存目前專案。切換專案時先上傳目前專案（含照片），再下載目標專案（含照片）。
- **收據照片**：拍照或選相簿，壓縮後存在手機（IndexedDB），離線可用。
- **收據辨識**：用 Gemini 讀照片，預填金額、日期、時間、地點、類別、付款方式、備註。有改變的欄位會用色框標示，確認後才儲存。
- **Google 雲端硬碟同步**：手動上傳、切換專案時自動同步。
- **整理總表**：把雲端所有專案整理成一份 Google 試算表，每個專案一個分頁。
- **匯出**：Excel（CSV）、分享備份、備份檔匯出與匯入。
- **離線**：加到主畫面後，記帳、編輯、查看都不需要網路。

## 一、發佈到 GitHub Pages

1. 把這個儲存庫設為公開。
2. **Settings → Pages**：Source 選 `Deploy from a branch`，Branch 選 `main` / `/ (root)`。
3. 網址是 `https://<帳號>.github.io/<儲存庫>/`。

## 二、安裝到手機

用手機連線打開網址一次，再加入主畫面：

- iPhone（Safari）：分享 → 加入主畫面
- Android（Chrome）：選單 → 安裝應用程式／加到主畫面

之後沒有網路也能開啟與記帳。

## 三、設定 Google 同步（只需一次）

1. 到 <https://console.cloud.google.com/> 建立專案。
2. **API 和服務 → 程式庫**，啟用：
   - **Google Drive API**（同步用）
   - **Google Sheets API**（整理總表用）
3. **Google Auth Platform**：
   - **品牌**：填應用程式名稱、使用者支援信箱、開發人員聯絡信箱。切換為正式版時需要：
     - 應用程式首頁：`https://adnan0721.github.io/japan-ledger/`
     - 隱私權政策：`https://adnan0721.github.io/japan-ledger/privacy.html`
   - **目標對象**：外部。維持「測試中」須加入測試使用者，授權約 7 天過期；發布為正式版則不會。App 只用 `drive.file` 這個非敏感權限，不需要送審。
4. **用戶端 → 建立用戶端**：類型選「網頁應用程式」，「已授權的 JavaScript 來源」填 `https://<帳號>.github.io`（只填網域，不含路徑與結尾斜線）。
5. 複製用戶端 ID（`xxxx.apps.googleusercontent.com`）。
6. 在 App：右上「同步」→ 貼上用戶端 ID →「儲存設定」。

第一次登入若出現「此應用程式未經驗證」，選「進階 → 前往」。

授權通行證有效約 1 小時，存在手機中；過期後再按需要連線的按鈕會重新登入。

## 四、設定收據辨識（選用）

1. 到 <https://aistudio.google.com/> 建立 Gemini API 金鑰。
2. 在 App：「同步」→ 貼上金鑰 →「儲存設定」。
3. 模型名稱預設 `gemini-flash-lite-latest`，可在同一畫面改成 AI Studio 上你可用的模型名稱。

注意：

- 金鑰只存在你手機的瀏覽器裡，**不要寫進程式碼或提交到儲存庫**，原始碼是公開的。
- 辨識時會把壓縮後的照片送到 Google。免費額度的內容可能被 Google 用來改善產品。
- 一張照片只辨識第一張；一張照片裡有多張收據時結果不可靠。

## 使用方式

### 記帳

「記一筆」填寫後儲存。點明細可編輯或刪除。有照片時可按「辨識收據（Gemini）」。辨識結果的行為：

- 金額、日期、時間、地點、類別、付款方式：辨識到就覆蓋，並標示變動。
- 備註：已包含辨識出的句子就不動，不包含就換行加在最後面，空的就直接填入。

### 專案頁（點上方專案名稱）

- **上傳專案與照片**：上傳目前專案與尚未上傳的照片。
- **切換專案**：按了才讀取雲端專案列表；選擇後先上傳目前專案，再下載目標專案與照片，成功後才清除手機上的舊專案。
- **新增旅行專案**：填專案名稱與持有現金（可留空），先上傳目前專案，再建立空的新專案。
- **目前專案設定**：名稱、匯率、出發日、回程日、持有現金、備註。
- **從手機移除**：只刪手機上的資料，雲端保留。
- 畫面顯示手機上的專案大小，以及雲端各專案的大小（記錄於上傳當時）。

### 同步畫面（右上「同步」）

- Google 用戶端 ID、雲端資料夾名稱、Gemini 金鑰與模型。
- **整理總表**：先上傳目前專案，再讀取雲端所有專案，寫入主資料夾裡的「旅費總表」（Google 試算表）。「總覽」分頁列出各專案合計；每個專案一個分頁，頂端有專案名稱、出發日、回程日、備註，不同日期的消費之間空一行，最後有合計。每次整份重寫，請勿手動在總表裡加內容。
- 程式版本與「更新到最新版」。
- 匯出 Excel（CSV）、分享備份、下載備份檔、匯入備份檔。

## 雲端硬碟結構

```
旅費帳本/                      ← 主資料夾（名稱可在同步畫面設定）
├─ 旅費總表                    ← Google 試算表
├─ 東京 5 日遊/
│   ├─ 旅費帳本-東京 5 日遊.json
│   └─ 收據-2026-10-10-990-ab12.jpg …
└─ 大阪京都 2026 春/
    └─ …
```

- 專案在 App 裡改名後，下次上傳會把雲端子資料夾一併改名。
- 資料夾與檔案以隱藏標記辨識，在雲端硬碟裡搬動位置，App 仍找得到。
- 權限為 `drive.file`，App 只能存取它自己建立的檔案。

## 資料與隱私

- 帳務資料在手機瀏覽器的 localStorage，照片在 IndexedDB。清除瀏覽器網站資料會一併刪除，重要資料請上傳。
- 沒有自己的伺服器，不蒐集任何資料。詳見 [隱私權政策](privacy.html)。
- 照片存手機的是壓縮版（最長邊 1280 像素、JPEG 品質 0.72），上傳雲端的也是這一份，App 不保留原圖。

## 更新程式

程式有兩處版本號，**每次更新都要一起加一**，手機才會取得新版：

- `index.html` 的 `VERSION`（畫面最下方顯示）
- `sw.js` 的 `CACHE`

連線時開 App 會自動抓新版；沒有換成新版時，到「同步」按「更新到最新版」。請勿刪除主畫面 App 再重加，在 iPhone 上這會連同手機上的資料一起刪除。
