# 旅費帳本

手機用的日本旅遊記帳 PWA。一次旅行一個專案，離線可用，只有同步需要網路。

- 記帳、查看、編輯、切換專案：完全離線
- 同步：手動上傳／下載到你的 Google 雲端硬碟（一個專案一個檔）
- 另有 JSON 匯出／匯入備份
- 資料存在手機瀏覽器內；Google 只會讓這個 App 看到它自己建立的檔案（`drive.file` 權限）

## 一、發佈到 GitHub Pages

1. 把這個資料夾推到公開儲存庫。
2. 儲存庫 **Settings → Pages → Build and deployment**：Source 選 `Deploy from a branch`，Branch 選 `main` / `/ (root)`。
3. 網址會是 `https://<帳號>.github.io/<儲存庫>/`。

## 二、安裝到手機（離線用）

用手機開上面的網址，**連線時先開一次**讓快取完成，再：

- iPhone（Safari）：分享 → 加入主畫面
- Android（Chrome）：選單 → 安裝應用程式／加到主畫面

之後沒有網路也能開啟與記帳。

## 三、設定 Google 同步（只需一次）

1. 開 <https://console.cloud.google.com/>，建立專案。
2. **API 和服務 → 程式庫**，搜尋 **Google Drive API**，按「啟用」。若要使用「整理總表」，也啟用 **Google Sheets API**。
3. **API 和服務 → OAuth 同意畫面**：
   - 使用者類型選「外部」，填 App 名稱與你的 Email。
   - 「測試使用者」加入你自己的 Google 帳號。保持「測試中」即可，不用送審。
4. **憑證 → 建立憑證 → OAuth 用戶端 ID**：
   - 應用程式類型選「網頁應用程式」。
   - 「已授權的 JavaScript 來源」填 `https://<帳號>.github.io`（只填網域，不含路徑與結尾斜線）。
5. 複製產生的用戶端 ID（`xxxx.apps.googleusercontent.com`）。
6. 在 App 內：右上「同步」→ 貼上用戶端 ID → 儲存。

## 使用

- **上傳到 Google 雲端**：把目前專案存成雲端檔案，同一專案會覆蓋舊檔。
- **下載其他專案**：列出雲端專案，點選後覆蓋或新增到手機。若手機版本較新會提示。
- 換手機時：同樣設定一次用戶端 ID，再下載專案即可。

## 注意

- 「測試中」狀態下，Google 授權約 7 天後會過期，再按同步重新登入即可，不影響手機上的資料。
- 清除瀏覽器網站資料會刪除手機上的帳，旅行期間請記得定期上傳。
- 更新程式後，請修改 `sw.js` 的 `CACHE` 版本字串，手機才會取得新版。
